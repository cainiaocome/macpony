# RPC API reference

All methods are sent as version-1 request envelopes. Python callers normally
use the typed namespace methods documented in [Python SDK](python-sdk.md), but
the lower-level `MacAPI.call()` can invoke any method listed below.

## Conventions

- IDs are generated by the SDK; callers supply only method parameters.
- `None` in the result column means the method returns no value.
- `FEATURE_DISABLED` means the operation is unavailable under current
  configuration or macOS capabilities.
- `INVALID_PARAMS` is returned for missing, empty, or incorrectly typed fields.
- `METHOD_NOT_FOUND` is returned for a method outside this catalog.

## System and protocol

| Method | Parameters | Result | Notes |
| --- | --- | --- | --- |
| `protocol.ping` | none | `{pong: true}` | Non-destructive transport check. |
| `system.capabilities` | none | `Capabilities` | Includes protocol, method, event, and feature catalogs. |
| `system.info` | none | `SystemInfo` | Hostname, macOS version, and host addresses. |
| `system.status` | none | `SystemStatus` | Tracked lock/sleep state and power information. |
| `system.userActivity` | none | `None` | Declares user activity to Hammerspoon. |
| `system.lock` | none | `None` | Dangerous action; disabled by default. |
| `system.screensaver` | none | `None` | Dangerous action; disabled by default. |

`system.lock` and `system.screensaver` return `FEATURE_DISABLED` unless
`MACAPI_ENABLE_DANGEROUS_ACTIONS=1` was present when Hammerspoon loaded the
configuration.

## Windows

| Method | Parameters | Result | Errors |
| --- | --- | --- | --- |
| `windows.list` | none | `list[WindowInfo]` | — |
| `windows.focused` | none | `WindowInfo \| None` | — |
| `windows.get` | `window_id: number` | `WindowInfo` | `WINDOW_NOT_FOUND`, `INVALID_PARAMS` |
| `windows.focus` | `window_id: number` | `None` | `WINDOW_NOT_FOUND`, `INVALID_PARAMS` |
| `windows.minimize` | `window_id: number` | `None` | `WINDOW_NOT_FOUND`, `INVALID_PARAMS` |
| `windows.unminimize` | `window_id: number` | `None` | `WINDOW_NOT_FOUND`, `INVALID_PARAMS` |
| `windows.maximize` | `window_id: number` | `None` | `WINDOW_NOT_FOUND`, `INVALID_PARAMS` |
| `windows.setFullscreen` | `window_id: number`, `enabled: boolean` | `None` | `WINDOW_NOT_FOUND`, `INVALID_PARAMS` |
| `windows.setFrame` | `window_id: number`, `frame: {x,y,w,h}` | `None` | `WINDOW_NOT_FOUND`, `INVALID_PARAMS` |
| `windows.move` | `window_id: number`, `position: WindowPosition` | `None` | `WINDOW_NOT_FOUND`, `INVALID_PARAMS` |

`WindowPosition` is one of `left-half`, `right-half`, `top-half`,
`bottom-half`, `center`, `maximize`, `top-left`, `top-right`, `bottom-left`,
or `bottom-right`.

## Screens

| Method | Parameters | Result | Errors |
| --- | --- | --- | --- |
| `screens.list` | none | `list[ScreenInfo]` | — |
| `screens.get` | `screen_id: str` | `ScreenInfo` | `SCREEN_NOT_FOUND`, `INVALID_PARAMS` |
| `screens.setBrightness` | `screen_id: str`, `brightness: 0..1` | `None` | `SCREEN_NOT_FOUND`, `FEATURE_DISABLED`, `INVALID_PARAMS` |
| `screens.screenshot` | optional `screen_id`, `mode: inline\|file` | `Screenshot` | `SCREEN_NOT_FOUND`, `SCREENSHOT_TOO_LARGE`, `FEATURE_DISABLED`, `INVALID_PARAMS` |

Inline screenshots contain a base64 PNG plus `width` and `height`. File mode
returns a path under the runtime directory and a `created_at` timestamp. The
file is local to the Mac running Hammerspoon; it is not transferred over the
socket.

## Input

| Method | Parameters | Result | Errors |
| --- | --- | --- | --- |
| `input.keystroke` | `key: str`, optional `modifiers[]` | `None` | `FEATURE_DISABLED`, `INVALID_PARAMS` |
| `input.type` | `text: str` | `None` | `FEATURE_DISABLED`, `INVALID_PARAMS` |
| `input.mouseMove` | `x: number`, `y: number` | `None` | `FEATURE_DISABLED`, `INVALID_PARAMS` |
| `input.mouseClick` | `button`, `x`, `y` | `None` | `FEATURE_DISABLED`, `INVALID_PARAMS` |

Supported modifiers are `cmd`, `ctrl`, `alt`, `shift`, and `fn`. Supported mouse
buttons are `left`, `right`, and `middle`. All input methods are disabled by
default.

## Event subscriptions

| Method | Parameters | Result |
| --- | --- | --- |
| `events.subscribe` | `subscriptions: [{event, include_data?}]` | normalized subscription list |
| `events.unsubscribe` | `subscriptions: [string\|object]` | `None` |
| `events.unsubscribeAll` | none | `None` |
| `events.getSubscriptions` | none | normalized subscription list |

Patterns ending in `*` match a prefix, for example `window.*`. See
[Events](events.md) for payloads and client-side queue behavior.
